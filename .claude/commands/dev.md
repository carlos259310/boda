# Skill: Iniciar servidor de desarrollo

Inicia el servidor de desarrollo de Astro en modo local.

## Proyecto activo
- Raíz: `/home/batman/boda/boda/`
- Framework: Astro 5.x
- Puerto por defecto: `http://localhost:4321`

## Comandos

```bash
npm run dev
```

## Notas
- El proyecto usa `src/` en la raíz (NO usar `astro-wedding/`)
- Los componentes están en `src/components/`
- La página principal es `src/pages/index.astro`
